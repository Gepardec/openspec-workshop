# Exercise B — ADD: Feeding Log

## Delta type
ADD

## Context
The baseline has no way to track whether an animal has been fed. A feeding log is a core operational feature for any zoo management tool — without it, the manager has no record of what was fed, when, and how much.

## User story to add
**US-07** — As a zoo manager, I want to log feeding events for an animal, so I have a record of what was fed, when, and in what quantity.

**US-08** — As a zoo manager, I want to see the feeding history for an animal on its profile, so I can quickly check when it was last fed and what it received.

## What participants do
Write a delta spec that introduces the feeding log as a new feature — covering the data model (new entity, relationship to animal), the API, and the UI (a log form + history list on the animal profile page).

## Learning outcome
Participants experience that ADD deltas require speccing a new feature from scratch, including data model decisions, API design, and UI placement — not just writing a user story.
