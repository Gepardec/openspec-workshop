# Baseline User Stories

These user stories define what the baseline app implements. They are intentionally written to reflect a first-pass interpretation of the requirements — not the final, correct version. The exercises build on top of this baseline by introducing spec deltas.

## Animal Management

**US-01** — As a zoo manager, I want to see a list of all animals in the zoo, so I have a quick overview of what animals are registered.

**US-02** — As a zoo manager, I want to view an animal's profile, so I can see its details including a free-text notes field for general observations.

**US-03** — As a zoo manager, I want to add a new animal to the registry, so newly acquired animals are tracked.

**US-04** — As a zoo manager, I want to update an animal's information, so the registry stays accurate over time.

**US-05** — As a zoo manager, I want to remove an animal from the registry, so animals that have left the zoo are no longer listed.

## Dashboard

**US-06** — As a zoo manager, I want a dashboard that spotlights a featured animal with its key stats and a fun fact, so I have an engaging starting point when I open the app.

---

> **Note for workshop facilitators:** US-02 intentionally includes a notes field that will be removed in Exercise A. US-06 intentionally implements the dashboard as an animal spotlight (featuring the cheetah) rather than an operational overview — this is corrected in Exercise C.
