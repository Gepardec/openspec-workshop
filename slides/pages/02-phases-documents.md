# The spec-driven Schema

Four artifacts, created in order:

| Phase | Artifact | Purpose |
|---|---|---|
| 1 | **Proposal** | What and why — the decision record |
| 2 | **Specs** | Acceptance criteria and constraints |
| 3 | **Design** | How — architecture and component decisions |
| 4 | **Tasks** | Ordered implementation steps for the AI |

---

# A Change is a Folder

```
openspec/changes/us-02-animal-profile/
  proposal.md      ← the why
  specs.md         ← the what
  design.md        ← the how
  tasks.md         ← the steps
```

All in Markdown. All in git. Reviewable, diffable, linkable.
