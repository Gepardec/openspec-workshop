# Übung 4 – Einen vorbereiteten Change anwenden

## Kontext

Im Unterordner `change/` liegt ein fertig ausformulierter Change. Kopiert ihn in `openspec/changes/`, wendet ihn an und archiviert ihn anschließend.

```sh
cp -r exercises/04_apply_change/change/* openspec/changes/
```

## Ziel

Den Change vollständig implementieren und archivieren.

## Erfolgskriterium

`openspec list` zeigt keine aktiven Changes. Die neuen Specs sind in `openspec/specs/` eingeflossen.
