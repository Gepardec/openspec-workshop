# Übung 2 – Workshop-Setup übernehmen

## Kontext

Das von `openspec init` erzeugte Verzeichnis ist bewusst minimal. Für die weiteren Übungen braucht ihr den vollständigen Workshop-Stand.

Kopiert das vorkonfigurierte `openspec/`-Verzeichnis in euer Repo-Root:

```sh
cp -r exercises/02_setup_openspec/openspec/ .
```

## Ziel

Erkundet das Setup — Changes, Specs und `config.yaml`. Die `config.yaml` ist jetzt mit vollständigem Projektkontext befüllt: Tech-Stack, Konventionen und Domain-Wissen, das OpenSpec bei der Generierung von Artefakten nutzt.

## Erfolgskriterium

`openspec list` zeigt `us-06-dashboard` als aktiven Change.
